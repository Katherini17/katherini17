### 🚀 Ключевые проекты

#### 📂 **[Менеджер задач](https://github.com/Katherini17/java-task-manager)**
REST API для управления задачами, пользователями, статусами и метками. Реализованы JWT-аутентификация, фильтрация и сортировка задач, а также частичное обновление ресурсов.
> **Используемые технологии:** Java 21, Spring Boot 3.4, Spring Security, Spring Data JPA, PostgreSQL, Docker, JUnit 5.

#### 📂 **[Анализатор страниц](https://github.com/Katherini17/java-page-analyzer)**
Веб-приложение для проверки доступности сайтов и базового SEO-анализа метаданных, включая Title, H1 и Description.
> **Используемые технологии:** Java 21, Javalin, JTE, PostgreSQL, Unirest, Jsoup, JUnit 5.

#### 📂 **[Валидатор данных](https://github.com/Katherini17/java-data-validator)**
Java-библиотека для валидации данных по схемам для различных типов данных.
> **Используемые технологии:** Java 21, JUnit 5, Gradle.
